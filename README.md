# Liquid Glass Keyboard

A working on-screen keyboard with a frosted "liquid glass" look, built as a single `index.html` with no dependencies.

## Features
- Letters, numbers/symbols and emoji layers
- Shift (tap once for one capital, double-tap for caps lock) and auto-capitalisation
- Delete with press-and-hold repeat
- Word suggestions above the keys
- Globe key cycles the background (Ocean, Dusk, Mint)
- Works with touch, mouse and a physical keyboard

## Run it
Open `index.html` in any modern browser. On a phone, open the published link below.

## Publish with GitHub Pages
1. Create a new repository on github.com (for example `liquid-glass-keyboard`).
2. Add `index.html` and `README.md` to it.
3. Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute your keyboard is live at `https://<your-username>.github.io/liquid-glass-keyboard/`.

## Note
This is a web keyboard that runs inside a page. A system-wide keyboard for iOS or Android needs native code (a keyboard extension in Swift, or an input method service in Kotlin).
